===========================================================
实验四：二阶电路响应的研究 - 数据处理工具说明
===========================================================

一、 实验目的
    本项目用于辅助完成《电路分析基础》实验四的数据处理与结论生成，主要功能：
    1. 判定并记录 RLC 二阶电路在不同电阻 R 下的三种响应状态（过阻尼、欠阻尼、临界阻尼）。
    2. 计算欠阻尼状态下的实验参数：衰减系数 α、振荡角频率 ωd 和阻尼比 ζ。
    3. 自动化比对实测临界阻尼电阻与理论值 R = 2√(L/C) 的误差。

二、 文件清单
    1. main.py        - 实验四处理脚本（支持参数计算与科学计数法格式化输出）
    2. data.csv       - 数据输入文件（需包含：L、C、各状态下的 R、波峰电压 u1m/u2m 及周期 T）
    3. README.txt     - 本说明文档

三、 运行环境
    - 运行环境：Python 3.x
    - 核心逻辑：内置了数学运算模块，支持将计算结果（如 2.09e+05）转换为标准学术写法（2.09×10⁵）。

四、 使用说明
    1. 数据准备：
       在 `data.csv` 中按要求填入：
       - 元件参数：电感 L (mH)、电容 C (μF)。
       - 临界阻尼：记录使波形刚好不产生振荡时的电阻 R 测量值。
       - 欠阻尼测量：记录 R = 100Ω 时的相邻波峰电压（u1m, u2m）及振荡周期 T。
    
    2. 执行脚本：
       运行 `python main.py`。
    
    3. 输出产出：
       程序将生成 `report_exp4.txt`。该文件包含了：
       - 三种状态的文字描述（可直接用于实验结论）。
       - 欠阻尼参数计算过程：
         * 对数减缩量 δ = ln(u1m/u2m)
         * 衰减系数 α = δ / T
         * 振荡角频率 ωd = 2π / T
       - 误差分析：实测临界电阻与理论值的百分比误差。

五、 实验要点提示
    - 临界阻尼判定：调节电位器使 $u_C(t)$ 曲线恰好不出现过冲（超调）且最快达到稳态。
    - 欠阻尼参数：测量波峰时，请注意示波器的基准线位置，确保电压差值的准确性。
    - 理论值参考：
        * 理论衰减系数 α = R / 2L
        * 理论角频率 ω0 = 1 / √(LC)

六、 注意事项
    - 如果 `data.csv` 缺失某些参数，脚本会在输出中以 “______” 留空，方便手动补全。
    - 确保 L 和 C 的单位换算正确（脚本内部已处理 mH -> H 和 μF -> F 的逻辑）。
