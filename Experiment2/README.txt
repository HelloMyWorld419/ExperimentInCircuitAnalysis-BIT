===========================================================
实验二：含源线性单口网络等效电路及其参数测定 - 绘图工具说明
===========================================================

一、 实验背景与目的
    本项目用于处理《电路分析基础》实验二的数据，主要功能包括：
    1. 验证戴维南定理（Thevenin's Theorem）与诺顿定理（Norton's Theorem）。
    2. 比较原始有源网络、戴维南等效电路、诺顿等效电路的外特性曲线（U-I 特性）。
    3. 通过线性拟合计算等效开路电压 Uoc 与等效内阻 R0，并对比多种测量结果。

二、 文件清单
    1. main.py        - 实验二自动化处理脚本（支持三种电路对比绘图）
    2. exp_2.csv      - 实验二原始数据文件（包含负载电阻、电压测量值及直接测量参数）
    3. README.txt     - 本说明文档

三、 运行环境
    - 运行环境：Python 3.x
    - 依赖库：pandas, numpy, matplotlib, scipy
    - 安装命令：pip install pandas numpy matplotlib scipy

四、 使用说明
    1. 数据录入：
       在 `exp_2.csv` 中填入实验测得的：
       - 原始网络在不同负载 RL 下的端口电压 UAB。
       - 直接测量的开路电压 Uoc、短路电流 Isc。
       - 半压法测得的内阻 R0 数值。
       - 戴维南与诺顿等效电路在相同负载下的输出电压。
    
    2. 执行计算：
       运行 `python main.py`。
    
    3. 产出物说明：
       - 2_Network_Comparison.png  - 三种电路的外特性对比图（验证等效性）。
       - report_copy_exp2.txt      - 包含拟合方程、内阻对比及实验结论的抄写手册。

五、 功能亮点
    - 多维度内阻对比：程序会自动对比“直接测量法”、“计算法”、“半压法”以及“曲线拟合分析法”得出的内阻 R0，并进行精度分析。
    - 自动化拟合：利用 scipy 的线性回归算法，精准绘制 U = Uoc - I * R0 的特性直线。
    - 实验报告友好：结论部分直接生成了符合学术要求的文字描述，可直接引用至电子版报告。

六、 实验结论要点（程序将自动填充数值）
    - 原始网络与等效网络的外特性曲线重合度说明。
    - 戴维南等效电路与诺顿等效电路的等效性验证。
    - 误差来源分析（如电压表内阻影响、调节误差等）。
