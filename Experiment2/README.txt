================================================================================
                 实验2：含源线性单口网络等效电路及其参数测定
                            数据处理程序使用说明
================================================================================

1. 程序功能概述
--------------------------------------------------------------------------------
本程序用于自动处理实验2的测量数据，完成以下任务：
  - 读取三组外特性测量数据（原始网络、戴维南等效电路、诺顿等效电路）
  - 根据负载电阻 RL 计算对应电流 I (mA)
  - 对每组数据进行线性拟合，得到开路电压 Uoc 和等效内阻 R0
  - 在同一坐标轴上绘制三条外特性曲线（U-I 图）
  - 生成实验报告所需的结论文本

2. 文件清单
--------------------------------------------------------------------------------
请确保以下文件位于同一文件夹内：
  - exp_2.csv          : 原始测量数据（需手工填写，格式见第4节）
  - main.py            : 主程序（Python 脚本）
  - README.txt         : 本说明文件

程序运行后会自动生成：
  - exp2_characteristic_curves.png : 外特性曲线对比图（300 DPI）
  - exp_2_final_report.txt         : 实验结论报告（拟合结果和验证结论）

3. 环境准备
--------------------------------------------------------------------------------
3.1 安装 Python
    推荐 Python 3.8 或更高版本。如未安装，请从 https://www.python.org/ 下载安装。

3.2 安装依赖库
    打开终端（命令提示符或 PowerShell），进入本文件夹，执行：
        pip install pandas numpy matplotlib scipy

    各库作用：
      - pandas    : 读取 CSV 数据
      - numpy     : 数值计算
      - matplotlib: 绘图
      - scipy     : 线性回归（linregress）

4. 准备测量数据（exp_2.csv）
--------------------------------------------------------------------------------
4.1 文件格式
    请使用文本编辑器（如记事本）或 Excel 编辑 exp_2.csv，严格按以下格式填写：

        Project,Point1,Point2,Point3,Point4,Point5,Description
        V_AB_Original(V),1.69,2.32,2.65,2.85,2.99,表格1:原始含源二端网络的输出电压VAB(单位:V)
        Direct_Measure,3.71,3.0,1210.0,1236.7,,
        V_AB_Thevenin(V),1.68,2.32,2.65,2.86,3.00,表格3:戴维南等效电路的输出电压VAB(单位:V)
        V_AB_Norton(V),1.65,2.27,2.60,2.80,2.94,表格4:诺顿等效电路的输出电压VAB(单位:V)

    - 第一行为列标题，不可修改。
    - 第2列至第6列（Point1 ~ Point5）对应负载电阻 RL 分别为 1kΩ、2kΩ、3kΩ、4kΩ、5kΩ 时测得的电压。
    - 每一行数据的定义：
        * V_AB_Original(V)   : 原始含源线性单口网络在对应负载下的输出电压 VAB (V)
        * Direct_Measure     : 直接测量参数行，依次填入：开路电压 Uoc (V)、短路电流 Isc (mA)、半压法测得的内阻 R0 (Ω)、开路电压短路电流法计算的内阻 R0 (Ω)。最后两列可留空。
        * V_AB_Thevenin(V)   : 戴维南等效电路在对应负载下的输出电压 VAB (V)
        * V_AB_Norton(V)     : 诺顿等效电路在对应负载下的输出电压 VAB (V)

4.2 数据填写要求
    - 所有电压数据必须为数值（浮点数或整数），不能留空或包含文字。
    - 如果某个测量值缺失，请补测后填入，否则程序会报错或拟合不准确。
    - Direct_Measure 行的第二列（Point1）为开路电压 Uoc，第三列（Point2）为短路电流 Isc，第四列（Point3）为半压法测得的 R0，第五列（Point4）为开路电压/短路电流法计算出的 R0。该行数据主要用于生成报告中的文字描述，不影响曲线绘制。

5. 运行程序
--------------------------------------------------------------------------------
5.1 打开终端，进入本文件夹（例如：cd D:\experiment2）
5.2 执行命令：python main.py
5.3 程序将依次：
      - 读取 exp_2.csv
      - 自动提取三组电压数据
      - 根据 RL=[1k,2k,3k,4k,5k] 计算对应的电流值（单位：mA）
      - 对每组 (I, U) 数据进行线性拟合，得到 Uoc 和 R0
      - 绘制三条 U-I 特性曲线（拟合直线 + 测量散点）
      - 保存图片和报告文本

6. 输出文件说明
--------------------------------------------------------------------------------
6.1 exp2_characteristic_curves.png
      满足实验报告要求的曲线图：
        - 同一坐标轴中绘制原始网络、戴维南等效、诺顿等效三条外特性曲线。
        - 横轴为电流 I (mA)，纵轴为电压 U (V)。
        - 每条曲线包含拟合直线（实线）和实际测量点（散点）。
        - 图例、网格、坐标轴标签齐全，标题为“图 2.7 原始网络与戴维南、诺顿等效电路外特性曲线对比”。
      请将此图插入实验报告电子版的“图2.7”位置。

6.2 exp_2_final_report.txt
      包含：
        - 三组特性曲线的线性拟合结果（开路电压 Uoc 和等效内阻 R0）。
        - 对戴维南定理和诺顿定理的验证结论。
      您可以直接将此文本复制到实验报告的“四、实验结论及总结”部分，或根据实际情况微调。

7. 核心算法说明
--------------------------------------------------------------------------------
程序采用最小二乘法线性拟合：U = Uoc - R0 * I
  - 截距（intercept）即为开路电压 Uoc
  - 斜率的绝对值即为等效内阻 R0
拟合基于测量得到的 5 个不同的负载点（RL = 1k~5k），能有效消除偶然误差，比直接测量开路电压和短路电流更准确。

8. 常见问题与注意事项
--------------------------------------------------------------------------------
8.1 中文字体显示问题
      若操作系统缺少 SimHei 或 Microsoft YaHei 字体，图表中的中文会显示为方框。解决方法：
        - 方法一：安装中文字体（如微软雅黑）。
        - 方法二：修改 main.py 中将 plt.rcParams['font.sans-serif'] 那行中的字体列表替换为系统已安装的字体（如 'Arial'），同时将图表标题和标签改为英文。

8.2 CSV 文件编码问题
      如果运行时报 UnicodeDecodeError，请用记事本打开 exp_2.csv，另存为 UTF-8 编码（选择“UTF-8”格式）后再运行。

8.3 数据点个数不一致
      程序会自动取每组数据的前5个有效数值。如果某一组电压数据少于3个点，拟合会失败。请确保至少测量了3个不同的 RL 值。

8.4 短路电流未测量
      报告中虽然会用到 Direct_Measure 行中的数据，但曲线的拟合不依赖该行。如果该行数据不全，不影响曲线绘制，但生成报告时 Uoc 和 Isc 会显示为 0。建议完整填写。

8.5 拟合结果与直接测量值不符
      线性拟合使用的是全部负载点数据，它代表了外特性的最佳逼近直线。理论上，拟合出的 Uoc 和 R0 与直接测量值（开路电压、短路电流）应非常接近。若有较大差异，请检查测量数据是否准确，或是否存在接线错误。
