================================================================================
                    实验5：R、L、C 单个元件阻抗频率特性测试
                            数据处理程序使用说明
================================================================================

1. 程序功能概述
--------------------------------------------------------------------------------
本程序用于自动处理实验5第一部分（阻抗频率特性）的测量数据，完成以下任务：
  - 读取您记录的 Ubc 电压值（mV）
  - 计算通过各元件的电流 I (mA) 和阻抗模 |Z| (kΩ)
  - 绘制电阻、电感、电容的 |Z|-f 特性曲线（实测点+理论曲线）
  - 生成完整的数据表格（CSV 格式）
  - 输出实验报告所需的所有数据和填空模板（report.txt）

2. 文件清单
--------------------------------------------------------------------------------
请确保以下文件位于同一文件夹内：
  - main.py          : 主程序（Python 脚本）
  - data.csv         : 您的原始测量数据（需手工填写）
  - requirements.txt : Python 依赖库列表
  - README.txt       : 本说明文件

程序运行后会自动生成：
  - impedance_results.csv          : 详细的计算结果表格
  - impedance_frequency_curve.png  : 阻抗频率特性曲线图（300 DPI）
  - report.txt                     : 实验报告填写模板（含数据、结论和填空项）

3. 环境准备
--------------------------------------------------------------------------------
3.1 安装 Python
    推荐 Python 3.8 或更高版本。如未安装，请从 https://www.python.org/ 下载安装。

3. 2 安装依赖库
    打开终端（命令提示符或 PowerShell），进入本文件夹，执行：
        pip install -r requirements.txt
    如果网络较慢，可使用国内镜像，例如：
        pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

    requirements.txt 内容如下：
        pandas>=1.3.0
        numpy>=1.21.0
        matplotlib>=3.4.0

4. 准备测量数据（data.csv）
--------------------------------------------------------------------------------
4.1 文件格式
    请使用文本编辑器（如记事本）或 Excel 编辑 data.csv，严格按以下格式填写：

        f_kHz,R_Ubc_mV,L_Ubc_mV,C_Ubc_mV
        10,10.9,125,134
        20,10.3,61.7,245
        30,10.5,43.9,380
        40,10.3,32.6,486
        50,10.4,25.0,600

    - 第一行为列标题，不可修改。
    - 每一行对应一个测试频率（单位：kHz）。
    - R_Ubc_mV : 电阻（2kΩ）两端测得的 Ubc 电压，单位 mV。
    - L_Ubc_mV : 电感（2.7mH）两端测得的 Ubc 电压，单位 mV。
    - C_Ubc_mV : 电容（0.1μF）两端测得的 Ubc 电压，单位 mV。

4.2 数据要求
    - 所有数据必须为数值，不能留空或包含文字。
    - 如果某个测量值缺失，请补测后填入，否则程序会报错。
    - 信号源有效值须保持 2V，程序按此固定值计算。若实际测试中信号源不是 2V，请调整电路使输出为 2V 后再记录数据。

5. 运行程序
--------------------------------------------------------------------------------
5.1 打开终端，进入本文件夹（例如：cd D:\experiment5）
5.2 执行命令：python main.py
5.3 程序将依次：
      - 读取 data.csv
      - 在控制台显示计算后的数据表格
      - 弹出阻抗频率特性曲线图（可手动保存或关闭）
      - 生成 impedance_results.csv、impedance_frequency_curve.png 和 report.txt

6. 输出文件说明
--------------------------------------------------------------------------------
6.1 impedance_results.csv
      包含频率、Ubc 测量值、计算出的电流 I (mA) 和阻抗模 |Z| (kΩ)。
      可用 Excel 打开，便于核对数据。

6.2 impedance_frequency_curve.png
      满足实验报告要求的曲线图：
        - 同一坐标轴中绘制 R、L、C 的 |Z|-f 特性。
        - 实心点+实线为测量值，虚线为理论值。
        - 图例、网格、坐标轴标签齐全。
      请将此图插入实验报告电子版的“图5.2”位置。

6.3 report.txt
      包含实验报告所需的所有内容和填空模板，分为三部分：
        - 第一部分：自动计算的数据表格（表5.1），可直接复制到报告中。
        - 第二部分：相位测量填空模板（需手动填写 Δt 和 Δφ）。
        - 第三部分：伏安关系轨迹线填空模板（需手动填写 2a、2b）。
        - 实验结论总结（可直接使用）。
      您只需根据示波器实际读数，将 report.txt 中的下划线“__________”替换为相应数值。

7. 常见问题与注意事项
--------------------------------------------------------------------------------
7.1 程序中文字体显示问题
      若操作系统缺少 SimHei 字体，图表中的中文会显示为方框。解决方法：
        - 方法一：安装中文字体（如微软雅黑）。
        - 方法二：修改 main.py，将 plt.rcParams['font.sans-serif'] 那行注释掉，此时图表标签会使用英文，不影响数据表达。

7.2 data.csv 数据缺失或包含非数字
      程序启动时会检查缺失值，若存在 NaN 或空值，会提示“请补全后再运行”。
      请确保每个频率下 R、L、C 三列都有有效数字（如电感 50kHz 的值需要实际测量）。

7.3 信号源有效值不是 2V
      本程序默认 Us = 2V。如果实验时使用了其他电压值，请修改 main.py 中的 US_V 变量（第 18 行附近）。

7.4 电感、电容的理论曲线参数
      理论曲线基于元件标称值：R = 2 kΩ，L = 2.7 mH，C = 0.1 μF。
      若您的实验箱元件参数与此不同，请修改 main.py 中的 R_NOM、L_NOM、C_NOM 变量。

7.5 运行时报错“No module named 'pandas'”
      说明未安装依赖库，请执行 pip install -r requirements.txt。

8. 实验报告填写提示
--------------------------------------------------------------------------------
  - 第一部分的数据表格直接复制 report.txt 中的表格内容，粘贴到实验报告表5.1处。
  - 曲线图使用生成的 impedance_frequency_curve.png，插入图5.2。
  - 相位的 Δt 和 Δφ 值，请根据示波器实际测量的延时填入 report.txt 对应的下划线处，然后将该部分文字复制到报告图5.3下方。
  - 轨迹线的 2a、2b 值，请根据 X-Y 模式下椭圆或直线的横纵轴长度（格数 × 伏/格）填入，并复制到报告图5.5下方。
  - 实验结论可以直接使用 report.txt 中给出的总结，也可根据实际情况微调。
