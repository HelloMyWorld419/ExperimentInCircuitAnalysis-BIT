===========================================================
实验五：R、L、C 单个元件阻抗频率特性测试 - 数据处理工具说明
===========================================================

一、 实验目的
    本项目用于自动化处理《电路分析基础》实验五的测量数据，主要功能包括：
    1. 计算 R、L、C 元件在不同频率下的电流 I (mA) 及阻抗模 |Z| (kΩ)。
    2. 绘制实测的阻抗-频率特性曲线（R-f, XL-f, XC-f），用于观察阻抗随频率变化的趋势。
    3. 自动生成实验报告文本，包含 X-Y 模式下李萨如图形的标注参数（2a, 2b）。

二、 文件清单
    1. main.py               - 实验五核心处理脚本
    2. data.csv              - 原始数据文件（需录入各频率下的 Ubc 测量值）
    3. impedance_results.csv - 自动生成的计算结果表格
    4. README.txt            - 本说明文档

三、 运行环境
    - 运行环境：Python 3.x
    - 依赖库：pandas, numpy, matplotlib
    - 安装命令：pip install pandas numpy matplotlib

四、 使用说明
    1. 数据准备：
       在 `data.csv` 中按频率（10kHz - 50kHz）填入示波器测得的采样电阻两端电压 Ubc (mV)。
       注意：信号源输出有效值 Us 需保持在 2V。
    
    2. 执行脚本：
       运行 `python main.py`。
    
    3. 输出产出：
       - impedance_frequency_curve.png：高清阻抗特性曲线图。
       - report.txt：包含自动生成的实验数据表格及结论总结。

五、 核心算法与标注说明
    - 阻抗计算：利用 $I = U_{bc} / R_{sample}$，进而得到 $|Z| = U_s / I$。
    - 相位标注（2a/2b）：
        * 在 X-Y 模式（李萨如图形）下，2a 代表椭圆在 Y 轴上的截距，2b 代表 Y 轴方向的峰峰值。
        * 脚本会自动根据你的 Ubc 测量值计算出建议的标注数值，方便填写报告中的图 5.5。
    - 曲线特性：
        * 电阻 R：曲线接近水平直线。
        * 电感 L：阻抗与频率成正比（感抗 $X_L = 2\pi fL$）。
        * 电容 C：阻抗与频率成反比（容抗 $X_C = 1 / 2\pi fC$）。

六、 注意事项
    - 绘图前请确保系统中已安装支持中文的字体（如黑体 SimHei），否则图片标注可能显示为方块。
    - 实验报告中的 X-Y 波形截图需手动插入，脚本提供的 a、b 计算值仅供参考。
