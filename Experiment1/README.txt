===========================================================
实验一：基本元件伏安特性的测绘 - 自动化绘图工具说明
===========================================================

一、 软件概述
    本项目是专为《电路分析基础》实验一开发的自动化数据处理与绘图脚本。
    程序能够自动读取实验测量数据，进行线性拟合和平滑曲线处理，生成符合
    实验报告要求的高清图表，并提供方便抄写的结论手册。

二、 文件清单
    1. main.py        - 核心执行脚本（基于 Python 3）
    2. exp_1.csv      - 实验数据输入文件（需手动录入数据）
    3. README.txt     - 本说明文档

三、 环境要求
    运行此程序需要安装以下 Python 库：
    - pandas          (数据处理)
    - numpy           (数值计算)
    - matplotlib      (科学绘图)
    - scipy           (曲线拟合与平滑插值)

    安装命令：pip install pandas numpy matplotlib scipy

四、 使用步骤
    1. 准备数据：
       打开 `exp_1.csv`，将实验中记录的线性电阻、二极管、电压源的 V/I 数值
       填入对应的单元格内，保存并关闭。
    
    2. 运行程序：
       在终端或 IDE 中运行 `python main.py`。
    
    3. 查看结果：
       程序运行完成后，将在当前目录下生成以下文件：
       - 1_Linear_Resistor.png      (线性电阻伏安特性图)
       - 2_Diode_Characteristic.png (二极管平滑曲线图)
       - 3_Voltage_Source_Comparison.png (电压源外特性对比图)
       - report_copy_exp1.txt       (实验数据对齐表及结论抄写手册)

五、 绘图技术细节
    - 线性电阻：采用最小二乘法进行线性拟合，并自动计算拟合电阻值。
    - 二极管：采用 Cubic Spline（三次样条插值）技术，解决手动描点不平滑的问题。
    - 电压源：支持理想电压源与实际电压源在同一坐标系下的对比显示。
    - 图片格式：300 DPI 高清分辨率，支持中文标注。

六、 注意事项
    - 请确保 CSV 文件中的 Project 列名称（如 'Linear_V' 等）不要被修改。
    - 若运行报错“未找到字体”，程序会自动回退到系统默认字体。
