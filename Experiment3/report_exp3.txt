一、RC 一阶电路零状态响应
------------------------------------------------------------
1. 输入信号：幅度 5V，周期 1ms，脉宽 0.5ms
2. 电路参数：R = 2kΩ，C = 0.01μF
3. 示波器测量结果：
   - 电容电压稳态值 uc(∞) = 5.2 V
   - 实测时间常数 τ = 20.0 μs
   - 理论时间常数 τ = R·C = 2000 × 0.01e-6 = 20 μs
4. 误差分析：相对误差 = |20.0 - 20.0| / 20.0 × 100% = 0.0%
5. 验证方法：从响应波形上升到 0.632Uc(∞) 处读取时间间隔。

二、RC 一阶电路零输入响应
------------------------------------------------------------
1. 输入信号：幅度 5V，周期 1ms，脉宽 3μs
2. 电路参数：R = 2kΩ，C = 0.01μF
3. 示波器测量结果：
   - 电容电压初始值 uc(0) = 0.792 V
   - 实测时间常数 τ = 19.2 μs
   - 理论时间常数 τ = 20 μs
4. 误差分析：相对误差 = |19.2 - 20.0| / 20.0 × 100% = 4.0%
5. 验证方法：从响应波形下降到 0.368Uc(0) 处读取时间间隔。

三、实验结论
------------------------------------------------------------
1. 零状态响应：电容电压从 0 按指数规律上升，最终趋于电源电压（约5V）。
2. 零输入响应：电容电压从初始值按指数规律衰减到 0。
3. 实测时间常数 τ 与理论值 20μs 接近，误差主要来源于示波器光标读数精度和电容/电阻标称值的偏差。
4. 加深了对 RC 一阶电路瞬态过程的理解，掌握了时间常数的测量方法。
