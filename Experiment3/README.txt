===========================================================
实验三：一阶电路响应的研究 - 数据处理工具说明
===========================================================

一、 实验目的
    本项目用于辅助完成《电路分析基础》实验三的数据整理，主要功能包括：
    1. 记录并计算 RC 一阶电路在方波激励下的零状态响应（充电过程）。
    2. 记录并计算 RC 一阶电路的零输入响应（放电过程）。
    3. 自动计算实测时间常数 τ，并与理论值（τ = RC）进行误差比对。

二、 文件清单
    1. main.py        - 实验三处理脚本（支持 CSV 读取或交互式手动输入数据）
    2. exp_3.csv      - 数据输入文件（需包含：稳态值、初始值及示波器测得的 τ）
    3. README.txt     - 本说明文档

三、 运行环境
    - 运行环境：Python 3.x
    - 依赖库：pandas
    - 安装命令：pip install pandas

四、 使用说明
    1. 数据准备：
       程序支持两种模式：
       - 模式 A：在 `exp_3.csv` 中按格式填入“测量项目”、“数值”和“单位”。
       - 模式 B：直接运行程序，根据控制台提示手动输入示波器屏幕显示的测量值。
    
    2. 执行脚本：
       运行 `python main.py`。
    
    3. 输出产出：
       程序将生成 `report_exp3.txt`。该文件按实验报告格式排列，包含了：
       - 零状态响应：uc(∞) 稳态值及 τ 的相对误差计算。
       - 零输入响应：uc(0) 初始值及 τ 的精度分析。
       - 填写建议：包含了如何从波形图中读取 0.632 倍或 0.368 倍位置的指导。

五、 技术要点
    - 理论值比对：脚本内置了 R = 2kΩ, C = 0.01μF 的标准参数，理论 τ = 20μs。
    - 自动化误差分析：程序会自动根据你的测量值计算绝对误差和百分比误差。
    - 截图引导：报告文本中预留了示波器截图的粘贴位置说明（如上升/下降沿放大图）。

六、 注意事项
    - 测量 τ 时，请务必在示波器上使用光标（Cursors）或自动测量功能以减小人为读数误差。
    - 确保输入单位的一致性（如 μs 或 ms），脚本会根据单位进行格式化输出。
